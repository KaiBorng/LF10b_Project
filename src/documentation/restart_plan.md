# Restart Plan after an incident

1. [Bootstick](https://www.youtube.com/watch?v=rWl9w8m0DBc) für debian erstellen
2. Zurücksetzen des Systems
3. [Debian]([url](https://github.com/KaiBorng/LF10b_Project/blob/main/src/documentation/Installation_debian.md)) aufsetzen
4. LXC konfigureren
5. [Ansible](https://github.com/KaiBorng/LF10b_Project/blob/main/src/documentation/automatisation/setup_system.md) installieren
6. Alles funktioniert wieder
