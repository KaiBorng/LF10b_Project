1. Take USB-Stick_5 and a Laptop or System
2. start the Laptop
3. press F12 until the Boot Manager opens
4. select the USB-Stick_5 and press enter
5. select the newest debian-live (debian-live-12.10.0-amd64-mate.iso) and press enter
6. select "Boot in normal mode" and press enter
7. select "start installer" and press enter
8. select your language (English) and press enter
9. select your location (United Kingdom) and press enter
10. select the keyboard layout (German) and press enter
11. wait a few moments
12. select your primary network interface (wlp0s20f3) and press enter
13. select your wireless network (MikroTik-AF2E92) and press enter
14. select if the network is open or requires a password (WEP/Open Network) and press enter
15. select tehe security key for your network (Kursiv: no input = no password) and press enter
16. wait a few monents
17. choose a hostname for your system (Server-MK-1 or Server-MK-2)
18. choose a domain name (Kursiv: no input = no domainname)
19. select root passwort (OW: root)
20. choose a name for a non admin user (user1)
21. choose a username for a non admin user (user1)
22. choose a password for the user (PW: user1)
23. select if the partition is Guided or Manual (Guided - use entire disc)
24. select the disk, where you want to save your OS (/dev/nvmeOn1 - 512.1 GB ...)
25. Select the Partitioning (All files in one Partition {recommended for new users})
26. press enter
27. klick YES and press enter
28. wait a few moments
